# Security Policy

## Project Scope

CipherScope is an educational cryptography visualization project implementing the Vigenère cipher, AES-128, and RSA for learning and demonstration purposes.

It is not intended for production cryptographic security.

## Supported Versions

Only the latest version on the `main` branch is actively maintained for project-related fixes.

| Version | Supported |
|---|---|
| Latest `main` | Yes |
| Older commits and releases | No |

## Reporting a Vulnerability

If you discover a security vulnerability in CipherScope, please report it privately to the repository maintainer through GitHub's available private vulnerability reporting feature, if enabled.

Include:
- A description of the issue
- Steps to reproduce it
- The potential impact
- Relevant logs or screenshots, with sensitive information removed

Please avoid publicly disclosing an unpatched vulnerability.

## Educational Disclaimer

CipherScope is intended for academic learning and algorithm visualization. Its implementations and demonstration parameters must not be relied upon to protect sensitive or production data.
